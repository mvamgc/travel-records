# Travel Records 

Travel records is designed to save pictures and notes during travel, organize the in photo albums and share them with friends or publicly.

While traveling the internet connection is not always available. Travel records can work in offline mode or with a bad internet connections, allowing to create albums, add picture description or just journal records offline and when internet available sync the data with the server. In case of a bad connection, the application can first synchronize text information and then downsized pictures, allows to share experience immediately and later sync up the picture in the high resolution.
