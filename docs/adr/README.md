# Architecture Decision Records

Each ADR records one significant design decision: its context, the options considered, the decision, and its consequences. ADRs are numbered in the order they were made and are never renumbered. A changed decision gets a new ADR, or an update to the affected one in the same pull request as the change.

The status of every ADR is listed in [HLD §11](../hld.md#11-decisions-adrs).
